Nurtura Menstrual Health Website

Nurtura is a full React & TypeScript web application with a secure private database. It runs on a local development server rather than static HTML files.

How to open the website:
  1. In your project folder, double-click: Start Nurtura.bat
  2. The launcher will automatically start the servers and open your browser to: http://localhost:5173
Open Nurtura (if already started)

If the server is already running in the background, clicking the button above will take you straight to your website!
